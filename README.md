## Engenharia na prática

### Arquitetura e sistemas distribuídos

Exploro separação de responsabilidades, Clean Architecture, padrões de projeto e comunicação entre serviços. Os estudos incluem aplicações com Spring Boot e Spring Cloud, configuração centralizada, descoberta de serviços e integração entre componentes.

### Eventos, dados e processos

Investigo integração orientada a eventos, Change Data Capture e orquestração de processos de negócio. Kafka, Debezium e Camunda aparecem nos projetos como ferramentas para estudar propagação de mudanças, sincronização de dados e fluxos entre serviços.

### Observabilidade

Estudo instrumentação de aplicações e ferramentas para compreender o comportamento dos sistemas. Os experimentos incluem OpenTelemetry com Spring Boot e ambientes de observabilidade com Grafana e Prometheus.

### IA e contexto de engenharia

No **MIA AI Memory**, exploro memória durável e compartilhada entre agentes, continuidade de contexto e rastreabilidade da informação. O repositório descreve uma arquitetura com core em Rust, API em Node.js, console em React e integrações via MCP.
